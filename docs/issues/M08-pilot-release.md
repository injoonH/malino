## Outcome

Operate a secure, measurable invite-only pilot for approximately ten users in Korea. Depends on M03–M07.

## Acceptance criteria

- [ ] Deploy the selected target with repeatable configuration, health checks, migration/rollback instructions, and secret handling.
- [ ] For Cloudflare: verify Free account/resources, actual limits, usage monitoring, CPU headroom, and graceful failure with no paid add-ons.
- [ ] For Pi: verify hardware/OS/storage, TLS/ingress, container permissions, persistent volumes, and restore procedure.
- [ ] Security tests, agreed performance budgets, Korean/English UI, mobile/IME, and keyboard/accessibility checks pass.
- [ ] Production Google configuration, privacy/support information, export/deletion, and restore evidence are ready.
- [ ] Rate/storage caps, signup kill switch, and incident procedure are documented.
- [ ] Record pilot feedback and actual daily quota/storage measurements without logging note bodies.

Keep registration invite-only. Public signup is a separate release decision.
